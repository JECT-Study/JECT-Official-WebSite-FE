# pr-create

현재 작업 브랜치를 push하고, 저장소의 PR 템플릿을 채워 GitHub PR을 생성한다. 핵심은 `.github/pull_request_template.md`를 단일 출처로 삼아 브랜치의 실제 변경 내용에 맞게 본문을 채우는 것이다(본문은 한국어).

## 항상 초안으로 연다

에이전트가 여는 PR은 예외 없이 `--draft`로 생성한다. 사람이 검증한 뒤 사용자가 직접 `gh pr ready <번호>`로 전환한다. 사용자가 초안이 아닌 PR을 요청하더라도 초안으로 만들고, 전환은 사용자 몫임을 알린다.

`--draft` 없이 `gh pr create`를 실행하면 PreToolUse 훅이 명령을 차단한다.

## 작업 순서

1. **브랜치 확인**: 현재 브랜치가 `dev`나 `main`이면 PR을 만들지 않는다. 사용자에게 알리고 작업 브랜치로 옮기거나 새로 만든다. base는 `dev`가 기본이며, 앞선 작업 브랜치에서 분기한 브랜치면 그 브랜치를 base로 지정한다(AGENTS.md의 Stacked PR). `main`은 운영 배포용이므로 base로 쓰지 않는다.
2. **변경 파악**: `git log dev..HEAD --oneline`과 `git diff dev...HEAD --stat`(필요시 전체 diff)로 이 PR이 담을 내용을 파악한다. 추측하지 말고 실제 커밋과 diff를 근거로 본문을 쓴다. 성격이 다른 작업이 섞여 있거나 한 번에 읽기 버거운 분량이면 나눌지 사용자에게 확인한다.
3. **커밋 상태 확인**: 커밋되지 않은 변경이 있으면 먼저 commit 스킬로 정리할지 확인한다.
4. **push**: `git push -u origin <branch>`. pre-push 훅이 타입 검사를 실행하므로, 실패하면 먼저 타입 에러를 해결한다.
5. **본문 작성**: 아래 "PR 본문" 절을 따른다.
6. **생성**: `gh pr create --draft --base dev --title "<제목>" --body-file <본문파일>`.
   - 제목은 커밋 컨벤션을 따른다: `<type>: <한국어 한 줄 요약>`.
   - 본문이 길므로 파일로 작성한 뒤 `--body-file`을 쓴다. 임시 파일은 스크래치패드 디렉토리에 만든다.
7. **결과 보고**: 생성된 PR URL과 함께, 리뷰 준비가 되면 `gh pr ready <번호>`로 전환하면 된다는 점을 알린다.

## PR 본문

1. 먼저 `.github/pull_request_template.md`를 읽어 현재 템플릿 구조를 그대로 가져온다.
2. 템플릿의 각 섹션을 브랜치의 실제 변경에 맞게 채운다.
   - **개요**: 이 PR이 무엇을, 왜 하는지 1~3줄.
   - **변경 사항**: 주요 변경을 항목으로. 커밋 목록을 그대로 베끼지 말고 의미 단위로 정리한다.
   - **관련 이슈**: 알고 있으면 `closes #N` 등, 없으면 해당 줄 제거.
   - **스크린샷**: UI 변경이 없으면 섹션째 제거.
   - **리뷰어에게**: 집중해서 봐야 할 부분, 논의가 필요한 결정, 아직 남은 작업.

   템플릿 섹션은 바뀔 수 있으므로 위 목록이 아니라 읽어온 템플릿을 기준으로 삼는다.

3. 템플릿 안의 HTML 주석(작성 가이드, GitHub Alert 예시 블록)은 본문에서 제거한다.
4. 리뷰어가 꼭 알아야 하는 내용이 있으면 GitHub Alert(`> [!IMPORTANT]` 등)를 쓴다. 남발하지 않는다.

## 검증

- lint, 포맷, 타입, 빌드, E2E는 CI가 검사하므로 본문에 통과 여부를 적지 않는다.
- 셸에 mise가 없으면 `mise exec -- pnpm <script>`로 실행한다.

## 주의

- `gh`가 인증돼 있어야 한다(`gh auth status`). 인증이 안 돼 있으면 `gh auth login`을 안내한다.
- 이미 같은 브랜치로 열린 PR이 있으면 새로 만들지 말고 기존 PR을 알린다(`gh pr view`).
- `gh pr ready`는 에이전트가 임의로 실행하지 않는다. 사용자가 명시적으로 요청할 때만 실행한다.
